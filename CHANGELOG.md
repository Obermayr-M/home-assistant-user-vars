# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-11-25

### Added

- Persistent typed user-specific values
- Boolean, string, integer, and number definitions
- UI management for add, edit, delete, and About
- English and German translations
- `set`, `get`, `toggle`, and `clear` actions for the calling user
- `list_values` and `clear_for_user` for administrators and internal automations
- HACS-compatible repository structure
- Garage request example

### Changed for public release

- New installations start with an empty definition set instead of an application-specific `garage_request` definition
